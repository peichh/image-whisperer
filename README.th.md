# Image Whisperer

**[English](README.md)**

Image Whisperer เป็น Agent Skill แบบโอเพนซอร์สที่ใช้ได้ฟรี มันช่วยเปลี่ยนคำขอภาพที่พิมพ์แบบบ้านๆ ทั้งภาษาไทยและภาษาอังกฤษ ให้เป็นพรอมต์ที่โมเดลสร้างภาพทำตามได้จริง ตัว skill ออกแบบโดยยึด Gemini เป็นหลัก ทั้ง Nano Banana, แอป Gemini, Gemini CLI และ Gemini API นอกจากนี้ยังรองรับ FLUX, Midjourney, Stable Diffusion/SDXL, Qwen-Image, Z-Image, Seedream และโมเดลที่ไม่รู้จักด้วย

Image Whisperer ไม่ใช่เครื่องสร้างภาพ ไม่ใช่เว็บไซต์ และไม่ใช่โมเดลที่ฝึกขึ้นมาใหม่ ตัวมันเป็นชุดคำสั่งที่เขียนด้วย Markdown ล้วน จึงไม่มี backend ไม่ต้องใช้ API key และไม่มีค่าใช้จ่าย

## ทำอะไรได้บ้าง

- **เข้าใจว่าจะเอาภาพไปใช้ทำอะไร** และเก็บทุกอย่างที่คุณบอกไว้ครบ ทั้งจำนวน ข้อความ สไตล์ และหน้าตาคนที่ต้องคงไว้ตามจริง ไม่เปลี่ยนคนธรรมดาให้กลายเป็นนายแบบ
- **เติมเฉพาะรายละเอียดที่ภาพต้องมี** เช่น แสง สถานที่ และมุมกล้อง แล้วบอกให้รู้ว่าเลือกอะไรให้เองบ้าง
- **ตรวจว่าฉากเป็นไปได้จริง** เช่น ทิศทางแสงตรงกันทั้งภาพ มีเงาตรงจุดที่วัตถุสัมผัสพื้น และท่าทางไม่ฝืนธรรมชาติ
- **เขียนพรอมต์ให้เข้ากับแต่ละโมเดล** และไม่ใส่คำสั่งที่โมเดลนั้นไม่รองรับ
  - Gemini, FLUX และ Seedream ได้พรอมต์เป็นประโยคบรรยาย
  - Midjourney ได้พรอมต์สั้นๆ ตามด้วย `--parameters`
  - SDXL ได้วลีกระชับพร้อม negative prompt
- **รองรับงานหลายแบบ** ได้แก่ แก้ภาพ, ใช้ภาพอ้างอิง, วิจารณ์ภาพที่สร้างแล้ว, ปรับพรอมต์เดิม และเทียบพรอมต์ระหว่างหลายโมเดล ไม่ต้องจำชื่อโหมด
- **ดึงความรู้มาใช้เฉพาะเท่าที่จำเป็น** เช่น กายวิภาค การถ่ายภาพ แสง วัสดุ การจัดองค์ประกอบ สี วิธีแก้ภาพที่ดูเป็น AI และสไตล์ 20 แบบ รวมถึงศิลปะไทย

## ติดตั้ง

ดูขั้นตอนทีละข้อได้ที่ [`docs/install.th.md`](docs/install.th.md) โดยสรุปคือ

| ใช้ที่ไหน | วิธี |
|---|---|
| แอป Gemini (บัญชีส่วนตัว) | อัปโหลดไฟล์ [`dist/image-whisperer.zip`](dist/image-whisperer.zip) ที่ **Skills → New skill → Upload** |
| Gems (บัญชีที่ทำงาน/โรงเรียน) | วางเนื้อหาจาก [`integrations/standalone/image-whisperer-instructions.md`](integrations/standalone/image-whisperer-instructions.md) ในช่อง Instructions |
| Gemini CLI | `gemini skills install https://github.com/peichh/image-whisperer.git` |
| Antigravity | คัดลอกโฟลเดอร์ไปไว้ที่ `.agents/skills/image-whisperer/` |
| ChatGPT, Claude และแชทอื่นๆ | วางไฟล์ standalone เป็น custom instructions |

## ผลการทดสอบ (วัดเฉพาะระดับพรอมต์)

เราทดสอบด้วย 110 เคส แบ่งเป็นภาษาไทย 55 เคสและภาษาอังกฤษ 55 เคส ครอบคลุม 31 หมวดและ 8 โมเดล แต่ละเคสเทียบพรอมต์ 3 แบบ ได้แก่ คำขอดิบ (A), การเติมคำแบบทั่วไปอย่าง "masterpiece, 8k" (B) และ Image Whisperer (C) ดูรายงานฉบับเต็มได้ที่ [`benchmarks/REPORT.md`](benchmarks/REPORT.md)

| ตัวชี้วัด | A ดิบ | B ทั่วไป | C Image Whisperer |
|---|---|---|---|
| เก็บสิ่งที่ผู้ใช้ขอไว้ครบ | 89.5% | 89.8% | 100.0% |
| คำที่เติมโดยไม่ได้ขอ (ต่อพรอมต์) | 0.00 | 8.07 | 0.00 |
| ความเจาะจงของฉาก | 16.8% | 56.6% | 83.2% |
| ความเข้ากันได้กับโมเดล | 28.2% | 81.8% | 100.0% |

**ข้อควรรู้:** การทดสอบนี้ไม่ได้สร้างภาพจริงเลย ตัวเลขข้างบนมาจากการตรวจคำในพรอมต์เท่านั้น และพรอมต์กับเกณฑ์ตรวจก็มาจากโปรเจกต์เดียวกัน ตัวเลขชุดนี้จึงใช้เป็นเกณฑ์กันถอยหลังเวลาแก้ skill ได้ แต่ไม่ได้พิสูจน์ว่าภาพจะออกมาสวยขึ้น ดูข้อจำกัดทั้งหมดได้ที่ [`docs/limitations.md`](docs/limitations.md)

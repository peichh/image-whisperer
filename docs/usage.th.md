# วิธีใช้ Image Whisperer

พิมพ์บอกสิ่งที่อยากได้ตามปกติ ไม่ต้องจำคำสั่งหรือชื่อโหมด

| อยากทำอะไร | พิมพ์ประมาณนี้ |
|---|---|
| ขอพรอมต์สร้างภาพ | "ขอรูปยายกับหลานทำขนมครกหน้าบ้าน ถ่ายด้วยมือถือ" |
| ระบุโมเดลที่จะใช้ | "...สำหรับ Midjourney" / "เอาไปใช้กับ FLUX" |
| แก้รูปที่มีอยู่ | แนบรูปแล้วพิมพ์ "เปลี่ยนพื้นหลังเป็นทะเล หน้าเหมือนเดิม" |
| ถามว่าภาพผิดตรงไหน | แนบรูปแล้วพิมพ์ "ทำไมดูเป็น AI" |
| ปรับพรอมต์เดิมให้ดีขึ้น | "ปรับพรอมต์นี้ให้ดีขึ้น: ..." |
| ใช้รูปอ้างอิง | "เอาหน้าจากรูปแรก ใส่ชุดจากรูปที่สอง" |
| เทียบหลายโมเดล | "ขอพรอมต์นี้สำหรับ Gemini กับ Midjourney" |

## สิ่งที่จะได้รับ

- **Prompt** อยู่ในกล่องโค้ด กดคัดลอกได้ทันที ปกติจะเขียนเป็นภาษาอังกฤษเพราะโมเดลส่วนใหญ่เข้าใจรายละเอียดภาษาอังกฤษได้ดีกว่า ส่วนข้อความที่ต้องอยู่ในภาพจะคงเป็นภาษาไทยไว้ในเครื่องหมายคำพูด
- **Settings** เช่น สัดส่วนภาพ จะแสดงเฉพาะเมื่อโมเดลนั้นมีให้ตั้ง
- **Assumed** คือสิ่งที่ระบบเลือกให้เอง เพราะคุณไม่ได้ระบุไว้ ถ้าไม่ตรงใจก็บอกแก้ได้

## เคล็ดลับ

- บอกว่าจะเอาภาพไปใช้ทำอะไร เช่น โพสต์เฟซบุ๊ก ปก YouTube หรือเมนูร้าน เพราะช่วยให้ได้ภาพที่ตรงงานมากที่สุด
- ถ้าอยากได้ภาพที่ดูธรรมดาและสมจริง ให้พิมพ์ "ถ่ายมือถือ" หรือ "ไม่ต้องสวยเกิน"
- ตัวหนังสือภาษาไทยในภาพยังออกมาเพี้ยนได้ในทุกโมเดล ควรใช้ข้อความสั้นๆ หรือเว้นที่ว่างไว้แล้วค่อยใส่ข้อความเองทีหลัง
- เวลาแก้ภาพ ให้แก้ทีละเรื่อง จะได้ผลแม่นกว่าการสั่งแก้หลายอย่างพร้อมกัน

# Integrations

| Where you use it | Folder | What to do |
|---|---|---|
| Gemini app (web, mobile, Mac) — personal accounts | `gemini-app/` | Upload `dist/image-whisperer.zip` as a skill |
| Gemini Gems — work/school accounts until Gems are retired | `gemini-gems/` | Paste instructions, add knowledge files |
| Gemini CLI / Antigravity | `gemini-cli/` | `gemini skills install …` or copy to `.agents/skills/` |
| Gemini API agents (your own code) | `gemini-api/` | Use the instructions as `system_instruction` |
| Any Agent Skills host (Claude, Codex, Cursor, …) | `agent-skills/` | Copy the folder into the host's skills directory |
| Any chat assistant (copy-paste) | `standalone/` | Paste `image-whisperer-instructions.md` |

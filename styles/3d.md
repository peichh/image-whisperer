# 3D render and 3D styles

## When

3D render, 3D character, clay, isometric, toy, Pixar-like, โมเดล 3 มิติ.

## Key traits

- Name the render look: soft clay render, glossy toy/vinyl, isometric low-poly, realistic PBR product render, stylised animated-film look.
- Lighting: studio three-point or soft global illumination; ground shadow.

## Prompt words

"3D clay render, soft global illumination", "isometric 3D low-poly scene", "cute 3D vinyl toy figure on a pastel background"

## Avoid

- mixing photo camera terms with toy renders
- studio names (describe the look instead)

## Model notes

All models handle these well.

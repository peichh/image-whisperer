# Character design sheets

## When

Character sheet, OC, mascot, turnaround, ออกแบบตัวละคร.

## Key traits

- Purpose: model sheet (front/side/back), expression sheet, outfit variations.
- Plain background, consistent proportions, labels optional.
- Mascots: simple silhouette, 2-3 main colours, readable at small size.

## Prompt words

"character turnaround sheet: front, side and back views on a plain white background, same character, same proportions"

## Avoid

- busy backgrounds
- inconsistent outfit between views

## Model notes

For consistency across many images, generate one master image and use it as a reference (Gemini, FLUX 3, Qwen-Image-Edit, Midjourney Edit Model).

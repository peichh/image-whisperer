# Cinematic stills

## When

Movie still, cinematic, film scene, หนัง, storyboard frame.

## Key traits

- Widescreen ratio (2.39:1 or 16:9), motivated light, colour grading, composition with depth, characters in mid-action.
- Only use when the user asks for a film look or the purpose is film/storyboard.

## Prompt words

"a film still", "anamorphic widescreen", "motivated practical lighting", "teal-and-amber grade" (only if wanted)

## Avoid

- using 'cinematic' as a generic quality word

## Model notes

Gemini: set aspect ratio in config. Midjourney: `--ar 21:9`.
